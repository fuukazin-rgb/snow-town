# snow-town ❄

Claude Code のデスクトップアプリ用の、背景テーマです。
雪の夜の街に雪が降り、**会話が進むほど（コンテキストを使うほど）地面に雪が積もっていきます。**
入力欄の下には、いま使っているトークン数と割合（例：`❄ 255,497 / 1,000,000 トークン（26%）`）を表示します。

- 0%：窓に明かりがともる街
- 70%：屋根だけが雪から出ている
- 100%：街はすっかり埋まり、雪だるまだけが残る

暗い画面（ダークモード）用に作っています。背景が表示されるのは、Claude のデスクトップアプリとモバイルアプリです（ターミナルでは背景は出ません）。

## 入れ方

Claude Code のターミナルの入力欄で：

```
/plugin install snow-town --marketplace niche-hobby/snow-town
```

聞かれたら `y` でマーケットプレイスを追加し、入れる範囲（user が先頭）を Enter で選びます。

シェル（ターミナル）から入れる場合：

```
claude plugin install snow-town --marketplace niche-hobby/snow-town
```

デスクトップアプリで `/plugin` が使えない場合は、入力欄の横の「＋」→「Plugins」→「Add marketplace」で `niche-hobby/snow-town` を追加し、「Add plugin」から入れてください。

## 使い方

- 入れると、次に始めた会話から背景が雪の街になります
- ほかのテーマに切り替えたあとは、`/snow` で雪の街に戻せます

## 表示している数字について

Claude Code が返答ごとに出している「コンテキストの使用量」をそのまま表示しています。

- 左：直前の返答で読み込んでいた会話の量（トークン数）
- 右：モデルが一度に覚えておける上限
- かっこ内：その割合（雪の積もり具合と同じ）

料金や累計の使用量ではありません。会話が自動で要約されたり `/clear` したりすると、数字と雪は減ります。
